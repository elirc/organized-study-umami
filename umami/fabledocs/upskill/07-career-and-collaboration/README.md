# 07 — Career and Collaboration

The technical skills get you the interview; these get you the offer and the promotion. Reviewing well, writing clear PRs/RFCs, and communicating with maintainers are what a mid-level engineer does beyond writing code — and they're what behavioral interviews probe.

Files:

1. [`01-code-review-mindset.md`](01-code-review-mindset.md) — the layers of review, a repo-specific checklist, example comments.
2. [`02-writing-prs-and-rfcs.md`](02-writing-prs-and-rfcs.md) — PR descriptions, commit messages, when to RFC, a repo-tailored RFC template.
3. [`03-maintainer-communication.md`](03-maintainer-communication.md) — asking for help without outsourcing thinking; repro reports; respectful disagreement; templates.

These skills feed directly into the behavioral round ([`../08-interview-prep/06-behavioral-star-stories.md`](../08-interview-prep/06-behavioral-star-stories.md)) and the review round ([`../08-interview-prep/05-debugging-and-code-review-rounds.md`](../08-interview-prep/05-debugging-and-code-review-rounds.md)).
