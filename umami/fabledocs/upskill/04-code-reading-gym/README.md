# 04 — Code Reading Gym

Reading code is a trainable skill, and most people never train it. This module is active practice, not prose: you annotate, trace, contrast, and review real Umami code, then self-grade.

Files:

1. [`01-annotation-drills.md`](01-annotation-drills.md) — 10 excerpts; annotate inputs/outputs/deps/invariants/side-effects/failure-modes.
2. [`02-trace-tables.md`](02-trace-tables.md) — 6 tables following data across files (UI→API, persistence, auth, error).
3. [`03-fake-code-contrasts.md`](03-fake-code-contrasts.md) — 10 bad-vs-better pairs tied to real repo patterns.
4. [`04-review-katas.md`](04-review-katas.md) — 10 fake PRs to review, graded blocking/important/optional.

How to use: do the exercise **before** reading the debrief. The value is in the attempt, not the answer. Fifteen minutes a day here will do more for your interview code-reading rounds than hours of passive reading.
